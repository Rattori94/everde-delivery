# everde

O everde é um site de delivery de comida 100% vegetal. Dá pra ver os restaurantes disponíveis, entrar no cardápio de cada um, adicionar pratos ao carrinho e seguir até o fim: entrega, pagamento e confirmação do pedido. É uma aplicação de verdade, com telas conectadas e um fluxo de compra completo simulado do início ao fim.

Esse projeto reaproveita um layout que eu já tinha usado no Figma pra um outro exercício (o efood), só que trocando a marca inteira pro tema verde e vegetal — cores, textos, ilustrações. Isso me obrigou a pensar em código de um jeito mais desacoplado: os componentes (cards, banners, cabeçalhos) precisavam funcionar do mesmo jeito não importa qual paleta ou conteúdo eu jogasse neles. Foi aí que caiu a ficha de por que gente separa tanto estilo de estrutura. Também foi meu primeiro contato mais sério com Redux Toolkit pra guardar o estado do carrinho global (que fica aberto ou fechado, com os itens dentro), e com formulários de verdade usando Formik e Yup — validando CEP, número de cartão, CVV e validade com máscara, e fazendo a exigência dos campos de pagamento aparecer só quando o usuário chega naquela etapa do carrinho. Simulei também uma API com RTK Query em cima de dados locais, então os componentes já lidam com loading e erro como se estivessem falando com um servidor de verdade — o que ajuda bastante se um dia eu quiser plugar um backend real sem reescrever tela nenhuma.

Tecnologias e ferramentas usadas: React com TypeScript, Vite, Redux Toolkit (com RTK Query), React Router, styled-components, Formik + Yup para os formulários e react-input-mask para as máscaras de campo.
